# Kivanto Free Local — Downloads

Installers and standalone packages for Kivanto Free Local.
Installationspakete und Standalone-Dateien für Kivanto Free Local.

[Releases & Downloads](https://github.com/KardungLa/kivanto-downloads/releases)

| Platform / Plattform | Package / Paket |
| --- | --- |
| macOS Apple Silicon | `macos-arm64` · `.dmg` |
| macOS Intel | `macos-x64` · `.dmg` |
| Windows 64-bit | `windows-x64` · `-de.exe` / `-en.exe` |
| Standalone | `.jar` · Java 25 |

The desktop installers include Java. Both installer languages support German and English in the application.
Die Desktop-Installer enthalten Java. Die Anwendung unterstützt in beiden Installervarianten Deutsch und Englisch.

Releases contain license terms in German and English and a `SHA256SUMS.txt` file for verifying downloads. Development builds are marked as pre-releases; unsigned packages are identified in their filenames and release notes.
Releases enthalten die Lizenzbedingungen in Deutsch und Englisch sowie eine `SHA256SUMS.txt` zur Prüfung der Downloads. Entwicklungsstände sind als Vorabversionen gekennzeichnet; unsignierte Pakete sind im Dateinamen und in den Versionshinweisen ausgewiesen.

Free Local is for one person on their own computer. Read the included license terms before installation.
Free Local ist für eine Person auf ihrem eigenen Rechner. Vor der Installation die beigefügten Lizenzbedingungen lesen.

## Website integration / Website-Anbindung

- Release overview: https://github.com/KardungLa/kivanto-downloads/releases
- Release API: https://api.github.com/repos/KardungLa/kivanto-downloads/releases

Use each release asset's `browser_download_url` for download buttons. Show development builds separately from stable versions and omit platforms without an available asset.
Für Download-Buttons die `browser_download_url` des jeweiligen Release-Assets verwenden. Vorabversionen getrennt von stabilen Versionen anzeigen und Plattformen ohne verfügbares Paket ausblenden.

This repository hosts download releases. Application source code is maintained separately.
Dieses Repository stellt Download-Releases bereit. Der Quellcode der Anwendung wird separat verwaltet.
